# ANPR Exit System

## Quick Start
```bash
python main.py
```
Or double-click `run_exit.bat`

## Access
- Web Interface: http://localhost:5001
- System Type: Exit Guard
- Camera Channel: Channel 2

## Features
- Vehicle exit detection
- License plate recognition
- Exit logging to database
- Guard authentication
- Live video feed from exit camera

## Installation
```bash
pip install -r requirements.txt
```

## Notes
- Runs on port 5001
- Uses camera channel 2 for exit detection
- Only logs vehicle exits to database

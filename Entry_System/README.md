# ANPR Entry System

## Quick Start
```bash
python main.py
```
Or double-click `run_entry.bat`

## Access
- Web Interface: http://localhost:5000
- System Type: Entry Guard
- Camera Channel: Channel 1

## Features
- Vehicle entry detection
- License plate recognition
- Entry logging to database
- Guard authentication
- Live video feed from entry camera

## Installation
```bash
pip install -r requirements.txt
```

## Notes
- Runs on port 5000
- Uses camera channel 1 for entry detection
- Only logs vehicle entries to database
